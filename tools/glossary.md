## 规则

- **保留英文**：产品与品牌名（GitHub、Copilot、Codespaces、Actions、Azure DevOps、MCP、Git、Markdown、VS Code 等）、键盘按键、文件名、代码标识符、反引号中的代码。
- **占位符** `{0}` `{1}` 必须原样保留，可以调整顺序。
- 句子用中文全角标点（，。？！：）；省略号与原文一致（`...` 或 `…`）。
- 中文与英文单词、数字、占位符之间加一个空格，例如「打开 GitHub」「{0} 个会话」。
- 按钮、菜单等短标签要简洁（通常 2～4 个字）。
- 不确定、或本身不该翻译的条目直接省略，界面会保留英文原文。
